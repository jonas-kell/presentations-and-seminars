# Info

This Presentation was as a conclusion to my Master Thesis. The thesis can be found here [Master-Thesis: Classical networks for the Hubbard model with a tilted potential](https://github.com/jonas-kell/master-thesis-documents).

## Summary

In the thesis the time-evolution of a `two-dimensional Hubbard model` on a square lattice is calculated, by applying a `cumulant expansion` as a perturbative approach.
This results in an analytical simplification. By then replacing the analytical pre-factors with variational parameters by application of `variational classical networks` a further improvement is targeted.
Finally the theoretical method is implemented and numerical experiments are run and presented.
